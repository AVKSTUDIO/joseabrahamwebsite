## Tech
- Single self-contained `index.html` (no build step, no external dependencies)
- Semantic HTML5, responsive CSS, inline SVG icons
- SEO: meta tags, Open Graph, Twitter Cards, JSON-LD (`ProfessionalService`) structured data, `sitemap.xml`, `robots.txt`, PWA manifest

## Files
| File | Purpose |
|------|---------|
| `index.html` | The complete one-page website |
| `assets/` | Logo, Open Graph image, favicons |
| `robots.txt` / `sitemap.xml` | Search engine directives |
| `site.webmanifest` | PWA / mobile install metadata |

## Deploy (GitHub Pages)
1. Push to `main`.
2. In the repo: **Settings → Pages → Source: Deploy from a branch → `main` / root**.
3. Site goes live at `https://avkstudio.github.io/joseabrahamwebsite/`.

> If deployed under a different domain, update the absolute URLs in `index.html` (canonical, Open Graph, JSON-LD), `sitemap.xml` and `robots.txt`.
